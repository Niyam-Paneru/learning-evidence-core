# Provenance

This repository extracts the evidence/mastery rules from private Niyam Learning OS work.

## Preserved

- assisted practice vs independent evidence;
- repeated independent success;
- spacing before durable mastery;
- refresh-due state;
- project-completion boundaries.

## Rewritten for public review

Learner history, exercises, personal progress data, UI state, voice features, and provider integrations are omitted.

## Claim boundary

This is a learning-state model, not an educational diagnosis or a claim that a particular learner has mastered anything.
