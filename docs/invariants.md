# Invariants

1. **Material help produces practice evidence.**
2. **Independent correct performance produces qualifying evidence.**
3. **One qualifying success is not durable mastery.**
4. **Repeated success without spacing is not durable mastery.**
5. **Old durable evidence can become refresh-due.**
6. **Evidence for one skill does not promote another skill.**
7. **Assisted project completion does not auto-promote prerequisites.**

Progress is allowed to feel good without becoming fake certainty.
