# Decisions

## Assisted success still counts — as practice

Calling assisted work “nothing” would be demotivating and inaccurate. Calling it independent mastery would also be inaccurate.

## Spacing matters

Two correct answers ten minutes apart are weaker retention evidence than two correct answers separated by time.

## Projects do not magically upgrade prerequisites

Finishing a project with help can be useful project evidence while still not proving independent command of every underlying skill.

## Refresh-due is not failure

Old durable evidence becomes a prompt to check retention, not a reason to erase history.

> XP is fun. Evidence is more useful when the answer actually matters.
